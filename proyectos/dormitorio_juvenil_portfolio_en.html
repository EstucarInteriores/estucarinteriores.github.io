shared kids’ bedroom · Madrid

Premium room-by-room design and furnishing without construction works.

Area 9 m²
Objective Reorganise rest, study and storage without irreversible solutions for a rental home
Resolution Layout, furniture and lighting without renovation. Furniture sourcing and procurement management
Context Documentation Proposal Result Contact

Context

Two siblings and a limited space designed to grow with them.

This project is set in a rental home. That constrains the intervention: the priority is not construction, but improving real everyday use with reversible solutions that do not compromise the property’s future.

With only 9 m², the goal was to make rest, study and storage coexist with order and without a sense of overload. The project starts from real measurements, a clear layout and a continuous system able to support two stages of use without having to redo the room in the short term.

Technical Documentation

Precise definition to execute without improvisation.

In projects without construction works, documentation is key so the final outcome matches the intent. Solid drawings lock in usable dimensions, proportions and system logic, avoiding interpretation during execution.

Layout with finishes · General view 2

Proposal

Organising everyday life so the room works effortlessly.

The proposal integrates rest, study and storage into one continuous system to avoid isolated pieces that reduce usable capacity and create visual noise. Dimensions and proportions are adjusted so the desk is truly comfortable, the sleeping area feels protected and storage responds to real needs.

The value of the project is not “adding things”, but ensuring everything fits: clear layout, friction-free circulation and a reversible solution that lasts and makes sense in a rental context.

Continuous system

One main element organises the three functions: a comfortable desk, real storage and a clean, calm front elevation.

  • Desk dimensioned for prolonged use.
  • Immediate storage + deeper storage (seasonal).
  • Rhythm: open niches, closed volumes and integrated light.

Proportion and real use

Dimensions and heights are tuned to avoid clashes, allow comfortable opening and keep light usable. Fully executable without construction.

  • Compartments designed for real-life use.
  • Task lighting + ambient lighting to reduce fatigue.
  • Reversible solution for a rental home.

Result

A small bedroom lived with order and calm.

The result holds thanks to layout and system logic: easier organisation, minimal interference between uses and a clean overall read. In 9 m², the goal is not “doing more”, but making everything easy to use and easy to maintain.
